# Space Invader HTML5

Canvas game created by Estefanía Fdez Muñoz. The original artwork and gameplay
are preserved, with native browser image loading instead of the old PreloadJS dependency.

## Run

Open `game.html` in a current browser, or serve the repository locally:

```bash
python3 -m http.server 8000
```

Open http://localhost:8000/game.html.

## Controls

- Left / right arrow: move the ship.
- Space: fire.
- R: restart after winning or losing.

The game uses keyboard controls and has no touch controls. Assets are local;
no account, remote API or build step is needed. This is a learning project,
not a production game. See CONTRIBUTING.md and SECURITY.md.
